# PROTOTYPE: Phone screens (throwaway)

Primary source for the wayfinder ticket "Phone screens" (Marcowich0/OpenStar#21).
This branch is never merged. Each file is a single self-contained page; open it in a browser
(on a desktop it shows a phone frame, on a real phone it fills the screen). Songs, people and lyrics
are invented; there is no real mic, server or audio.

| File | Round | What it asks |
|---|---|---|
| `round1-three-takes.html` | 1 | Three takes on the whole Phone flow (joining, the Remote and the mic screen): A Tabs, B One scroll, C Thumb deck. |

Controls: the dark panel on the left jumps to any scene and fires events from elsewhere (the Stage seats me,
someone presses Start, the Phone locks mid-song). Left and right arrow keys switch the take. On a phone, the
PROTO pill top right opens the same panel. Location: `#<take>-<scene>`, for example `#b-mic-singing`.
Palette colours 9 to 12 are placeholders until "Twelve-colour palette" (#26) settles them.
