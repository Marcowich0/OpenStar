# PROTOTYPE: Visual direction (throwaway)

Primary source for the wayfinder ticket "Visual direction" (Marcowich0/OpenStar#19).
This branch is never merged. Each file is a single self-contained HTML page; open it in a
Chromium browser. Songs, lyrics and singers are invented and simulated; there is no audio.

| File | Round | What it asked |
|---|---|---|
| `round1-three-takes.html` | 1 | Three looks for the song browser and sing screen: A Bubble Pop, B Stage Night, C Sticker Book. **A won.** |
| `round2-sing-over-video.html` | 2 | A's sing screen over the music video, three ways to show several Players: split lanes, filled notes, comet tails. |
| `round3-five-layouts.html` | 3 | Five layouts over the video: top & bottom, corner pods, lower third, highways, still lanes. **Lower third won.** |
| `round4-eight-players.html` | 4 | Lower third stretched to 8 Players, plus shared-field alternatives. **Two columns won.** |

Controls: the bar at the bottom. ←/→ switches take, `h` hides the bar, `i` shows notes on the take.
URL parameters: `?variant=…&screen=sing|browser&players=1-8&duet=0|1&seek=<beats>`.
"video…" in rounds 2–4 plays a real video file behind the sing screen.
